## 二、新增功能

### 1. 深色模式

`App.axaml` 从单一资源字典改为 **Light / Dark 两套 `ResourceDictionary`**，主题色分别定义：

| 角色 | 浅色 | 深色 |
|---|---|---|
| 强调色 | `#2564CF` | `#4C8DFF` |
| 悬停 | `#1B4EA8` | `#6FA5FF` |
| 浅强调背景 | `#E8F0FD` | `#1F3A5F` |

- 三种模式：`0` 浅色 / `1` 深色 / `2` 跟随系统（`AppSettings.ThemeModeIndex`，默认 2）
- 切换逻辑在 `MainViewModel.OnThemeModeIndexChanged` → 设置 `Application.RequestedThemeVariant`
- 弹窗（`MessageBox`）也一并主题化，深浅色一致

### 2. Fluent 半透明界面

- 窗口 `TransparencyLevelHint="AcrylicBlur"` —— 桌面磨砂透过
- 大面积面板色改为**带 alpha 的 `SolidColorBrush`**（如 `#D8F3F2F1`、`#E6FFFFFF`），配合亚克力背景
- 新增 `VeilBrush` + `VeilOpacity` 遮罩层：没有壁纸时让桌面磨砂透出
- 支持**自定义壁纸**（`AppSettings.WallpaperPath`）与**透明度滑块**（`WallpaperOpacityPercent`，0–85，默认 30）
- `MainViewModel` 新增 `SetWallpaper(path)` / `ClearWallpaper()` / `LoadWallpaper(path)`

### 3. 托盘常驻

`App.axaml` 内声明 `TrayIcon`（非代码创建）：

```xml
<TrayIcon ToolTipText="作业提醒 · 长江雨课堂" Icon="/Assets/app.ico">
  <TrayIcon.Menu>
    <NativeMenu>
      <NativeMenuItem Header="打开主界面" Click="OnTrayOpenClick" />
      <NativeMenuItem Header="退出" Click="OnTrayQuitClick" />
    </NativeMenu>
  </TrayIcon.Menu>
</TrayIcon>
```

配套的关闭行为（`MainWindow.OnWindowClosing`）：

- 点关闭**不直接退出**，先弹三选一确认框（`MessageBox.ConfirmCloseAsync`）
- 选「最小化」→ `Hide()`，窗口从任务栏消失，只剩托盘图标
- 选「退出」→ 置 `_allowRealClose` 后真正关闭
- `ShowFromTray()` / `QuitForReal()` 供托盘菜单调用

### 4. 登录页窗口自适应

`MainWindow` 新增两种尺寸模式，随 `ShowLogin` 切换：

| 模式 | 尺寸 | 可拉伸 |

| 登录页 | 480 × 700（与二维码页面尺寸相当） | 否 |
| 主界面 | 1180 × 760（最小 960 × 580） | 是 |

并新增 `CenterOnScreen()`：登录成功后窗口从紧凑尺寸放大，若不重新居中会以左上角为锚点膨胀到屏幕外。

### 5. 自绘程序图标

新增 `HomeworkReminder/Assets/app.ico`（30 KB）与 `app.png`（13 KB），统一用于：

| 位置 | 引用点 |
|---|---|
| 窗口标题栏 | `MainWindow.axaml` → `Icon="/Assets/app.ico"` |
| 任务栏 / exe 文件图标 | `HomeworkReminder.Desktop.csproj` → `<ApplicationIcon>` |
| 托盘 | `App.axaml` → `TrayIcon.Icon` |
| 弹窗 | `MessageBox.cs` → `avares://HomeworkReminder/Assets/app.ico` |

### 6. 学期 / 学校可配置

新增 `Services/AppSettings.cs`，持久化 `settings.json`（与会话文件同目录）：

| 字段 | 默认 | 说明 |
|---|---|---|
| `UniversityId` | 3214 | 高校 id |
| `Term` | 202601 | 学期标识 |
| `WallpaperPath` | null | 壁纸本地路径 |
| `WallpaperOpacityPercent` | 30 | 背景透明度 0–85 |

## 三、架构性改进

### 1. 反射式 JSON → 源生成上下文（为裁剪发布铺路）

新增 `Services/AppJsonContext.cs`，用 `[JsonSourceGenerationOptions]` + 21 条 `[JsonSerializable]` 覆盖**全部**序列化点：

- 雨课堂 DTO：`YktCourse` / `YktActivity` / `YktProgressData` / `YktLeafDetail` / `YktChapter` / `YktUserProfile` / 两个请求体
- 本地持久化：`SessionFile` / `ProtectedEnvelope` / `LocalState` / `AppSettings`

调用点已全部改为 `AppJsonContext.Default.Xxx`（`YktApiClient`、`SessionStore`、`LocalStateStore`、`AppSettings`、`YktJsonConverters`）。

**为什么必须这么做**：裁剪发布（`PublishTrimmed`）会移除反射序列化所需的元数据，反射式 `JsonSerializer` 在运行时报
「Deserialization of types without a parameterless constructor」——历史上表现为**登录后同步即崩**。

容错选项（大小写不敏感、数字可从字符串读出、容忍尾逗号/注释）被烘进生成代码，与旧反射路径行为一致。上下文声明为 `internal`，因为包含 `internal` 的 `ProtectedEnvelope`，`public` 会导致 CS0053。

配套：`Desktop.csproj` 保留 `JsonSerializerIsReflectionEnabledByDefault=true` 仅作漏网路径兜底。

### 2. 会话文件 DPAPI 加密

新增 `Services/Dpapi.cs`：`crypt32.dll` 的 `CryptProtectData` / `CryptUnprotectData` P/Invoke 封装，语义等价于
`ProtectedData` + `DataProtectionScope.CurrentUser`（**只有同一台机器上的同一 Windows 用户能解密**）。

- 落盘格式：`{ "protected": true, "data": "<base64>" }`
- **向后兼容**：仍能读旧的明文格式；读取后下次保存自动升级为加密格式
- 非 Windows 无 DPAPI → 回落明文
- DPAPI 不可用时（如受限的服务会话 0）→ 宁可明文保存，也不让「保存登录态」整个失败
- 换用户/换机器解密失败 → 按「未登录」处理，不崩溃
- 异常捕获覆盖 `IOException / JsonException / UnauthorizedAccessException / FormatException / Win32Exception / ExternalException`

**不用 NuGet 包的原因**：`System.Security.Cryptography.ProtectedData` 不在仓库的离线包源与机器缓存中，
restore 拿不到（NU1101）；而这两个 API 自 Windows 2000 起内置在 crypt32.dll，P/Invoke 无额外依赖。

### 3. 平台服务抽象

新增 `Services/IPlatformServices.cs`，把 `Process.Start` 这类平台 API 移出共享项目：

- `OpenUrl(string)`，实现应自行吞异常
- 桌面实现：`HomeworkReminder.Desktop/DesktopPlatformServices.cs`
- 在 `Program.Main` 早期注入到 `MainViewModel.PlatformServices`

注释里明确记录了**已知取舍**：`Avalonia.Controls.NativeWebView` 仍直接出现在共享项目里
（`LoginView.axaml` 直接宿主、`MainViewModel.CompleteLoginAsync` 签名接收它），彻底抽离需把登录视图整体挪到 Desktop 头，本次刻意不做。

### 4. 自检体系扩展

`Program.cs` 现有 6 个开关：

| 开关 | 作用 |
|---|---|
| `--selfcheck [png]` | 窗口/绑定自检 + 离屏渲染（原有，已扩展） |
| `--webtest [秒]` | WebView 登录链路探测（原有） |
| `--logintest [秒] [--logout]` | 登录流程 + 退出登录回归（原有，新增 `--logout`） |
| `--cookietest [秒]` | WebView Cookie 读取与清除专项（原有） |
| **`--jsoncheck`** | **新增**：全部序列化路径往返自检 |
| `--selfcheck-login` | 强制停在登录页再渲染 |

**`--jsoncheck` 的价值**（新增 `Services/JsonSelfTest.cs`）：把每个参与 JSON 往返的类型用**生产同一份 options**
各跑一遍真实序列化/反序列化，反射元数据缺失会在这里原样抛出线上同款异常——**使 trim 包无需登录即可验证**。
退出码 0 = 通过，1 = 有失败明细。

覆盖 7 个线上载荷样本（含 `score_d` 为字符串、`leaf_schedules` 混合形态、`avatar` 的 http→https 提升等容错点）
+ 3 个真实 Store 往返（`SessionStore` 含 DPAPI 信封、`LocalStateStore`、`AppSettings`）。

## 四、发布与打包

`tools/publish.ps1` 的模式从 3 个扩展到 4 个，新增 **`trim`**（裁剪单文件）：

```powershell
'SelfContained=true'
'PublishSingleFile=true'
'IncludeNativeLibrariesForSelfExtract=true'
'PublishTrimmed=true'          # 部分裁剪：只裁框架与可裁剪包，业务程序集保留
```

`publish/` 目录实测（截至扫描时）：

| 模式 | 主 exe | 目标机要求 |
|---|---|---|
| `trim` 裁剪单文件 | **40.6 MB** | 无（推荐分发） |
| `single` 完整单文件 | 100.3 MB | 无 |
| `sc` 自包含多文件 | 0.2 MB（+ 大量依赖文件） | 无 |
| `fdd` 框架依赖 | 0.2 MB（45.9 MB 目录） | 需 .NET 10 桌面运行时 |

`CHANGELOG.md` 记录：分发前需删除产物目录中的 `<exe>.WebView2` 文件夹——实测该目录 **67 MB**，
内含本机登录 cookie 缓存与渲染缓存，不应随包分发。

未采用 Native AOT：需要 ILCompiler 包与 MSVC 工具链，当前离线环境做不了。

## 七、对 Agent 交付内容的保留情况

此前记录的 11 条「踩坑」修复**全部保留**，未被回退：

1. `leaf_schedules` 的键是章节项 `id`，不是 `leafinfo_id`
2. 数值字段类型不稳定 → `YktNumber` 容错
3. 同步不能跑在 UI 线程上
4. 自定义 CheckBox 模板必须保留 `ContentPresenter`
5. WebView2 初始化失败会杀掉整个进程
6. 登录检测的两个坑（WebView 线程亲和性、`InvokeScript` 不等待 Promise）
7. 登录页自动检测已有登录态
8. 按钮可点性不能绑定「全局忙碌」，同步也不能被登录挡住
9. 退出登录必须清 WebView 的 Cookie
10. 「在浏览器中打开」不能凭直觉拼路径（`YktUrls`）
11. Avalonia 12 的破坏性改动

改动方式以**增量**为主：新增 `AppJsonContext` / `Dpapi` / `AppSettings` / `IPlatformServices` / `JsonSelfTest`，
在既有文件上扩展而非重写。
